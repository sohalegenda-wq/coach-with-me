# Публикация на Cloudflare Pages Free

## 1. Исходники в GitHub

Файлы проекта подготовлены в репозитории `sohalegenda-wq/coach-with-me`. Они не отправляются на GitHub автоматически. Просмотрите изменения и создайте коммит через ваш обычный процесс. В Git не должны попадать `.env.local`, секреты Edge Functions, `node_modules` и файлы с паролями.

## 2. Создайте проект Pages

1. В Cloudflare Dashboard выберите **Workers & Pages → Create → Pages → Connect to Git** (названия пунктов могут незначительно отличаться).
2. Подключите GitHub и разрешите доступ к `sohalegenda-wq/coach-with-me`.
3. Выберите production branch `main`.
4. Framework preset: **None** или **Vite**.
5. Build command: `npm run build`.
6. Build output directory: `dist`.
7. Root directory: корень репозитория (пустое поле). В cloud workspace путь `/workspace/coach-with-me` нужен только локально; его не вводят в Cloudflare.
8. Node.js: задайте `NODE_VERSION=24.19.0` в переменных сборки, либо совместимую версию 22.12+.

У Pages не требуется команда `npx wrangler deploy`. Если журнал содержит `Worker Name` и `Executing user deploy command: npx wrangler deploy`, создан проект Workers. Чтобы использовать запрошенный Pages, создайте именно Pages-проект с настройками выше. Удалять существующий Worker для этого не требуется.

## 3. Переменные сборки

Задайте для Production (и Preview при необходимости):

```text
VITE_SUPABASE_URL = https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY = YOUR_PUBLISHABLE_OR_ANON_KEY
```

Используйте **корневой URL** без `/rest/v1`. Эти два значения публичные. Cloudflare не исполняет Edge Functions Supabase и не нуждается в service_role / AI_API_KEY / DATABASE_URL.

Нажмите Deploy. Сборка установит зависимости по `package-lock.json` и создаст статические файлы в `dist/`. После изменения VITE-переменных обязательно пересоберите сайт — они встраиваются во время сборки.

## 4. Свяжите домен с Auth и функциями

После получения адреса `https://YOUR_SITE.pages.dev`:

1. В Supabase Auth установите этот Site URL и Redirect URLs (см. SUPABASE.md).
2. Добавьте адрес в `ALLOWED_ORIGINS` Edge Functions.
3. Убедитесь, что обе функции развернуты.
4. Проверьте email-письма, вход и отправку практики с опубликованного сайта.

Маршруты используют `#/academy`, `#/lesson/...`: часть после `#` обрабатывается браузером, сервер всегда получает корневой путь `/`. Поэтому файл `_redirects` и правило `/* /index.html 200` не нужны. Такое правило может отклоняться Cloudflare Static Assets с ошибкой `Infinite loop detected` (100324). Не добавляйте его при публикации через Pages или Workers.

`public/_headers` автоматически копируется Vite в сборку. CSP разрешает запросы только к `*.supabase.co`; API ИИ вызывается с сервера, его домен в браузере не нужен.

Если у Supabase свой API-домен, добавьте точный HTTPS/WSS origin в `connect-src` файла `public/_headers` и пересоберите. Не ослабляйте всю CSP. Секретов в HTML/JS быть не должно; только публичный Supabase key.

## 5. Обновления

После push в `main` Cloudflare запускает новую сборку. Изменения БД применяются отдельно через новые Supabase-миграции, функции — через `supabase functions deploy`. Изменения курсов, уроков и вопросов из админ-панели сохраняются в базе и видны аккаунтам без новой сборки. Открытый каталог при настроенном подключении тоже загружается из БД; локальный встроенный каталог используется при отсутствии подключения.

Не загружайте весь репозиторий как статический сайт: папка публикации — только `dist/`. SQL, исходники серверных функций и тестовые файлы не должны обслуживаться Pages.

## 6. Бесплатный запуск

Обязательных платных компонентов в архитектуре нет. В Free действуют лимиты сборок/запросов/БД/Auth/функций и возможная пауза неактивного проекта. SMTP и ИИ имеют отдельные квоты выбранного провайдера. Следите за usage в панелях. Статические материалы и учебный режим наставника продолжают работать при отключении ИИ; сохранение аккаунтов требует доступного Supabase.

Публикацию выполняет владелец аккаунта Cloudflare. Исходники и локальная сборка сами по себе не означают, что сайт опубликован.
