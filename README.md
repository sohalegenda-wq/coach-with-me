# CWM — Coach With Me

Академия футбольных тренеров FTCL: адаптивный интерфейс на **HTML5, CSS3 и JavaScript**, **Cloudflare Pages**, **Supabase PostgreSQL / Auth / Edge Functions**. Обязательная платная подписка не нужна. ИИ подключается отдельно; без него учебный процесс работает.

## Что реализовано

- Регистрация (никнейм, уникальное имя, email, пароль и подтверждение), вход, выход, восстановление и смена пароля через Supabase Auth. Между устройствами синхронизируются профиль, черновики, результаты, сообщения и лицензии.
- 5 курсов, 19 уроков, учебный цикл «теория → объяснение → вопросы → доска → обратная связь → закрепление». Завершение проверяет сервер, кнопки «просто завершить» нет.
- Тактическая доска с 11 игроками, мышью, касанием и клавиатурой; 3 расстановки, давление, ширина, стиль атаки, замены и объяснение.
- Coach CWM: подготовленный учебный режим, три формата занятия, история, подключаемый ИИ через защищённую Edge Function и переход на учебный режим при ошибке/лимите.
- Пробный тест и официальные экзамены D/C/B/A/Pro: 20 вопросов × 2 и 3 письменные задачи × 20. Итог от 70 — лицензия. Письменные работы оценивает администратор по четырём критериям 0–5. ИИ не выдаёт лицензии.
- Администратор: пользователи и блокировки, выдача/отзыв лицензий с причиной, курсы и уроки, экзаменационные вопросы, очередь письменных работ, отмена попыток, статистика, лимиты ИИ, журнал действий.
- RLS, закрытые ключи экзаменов, снимки вопросов и ответов для каждой попытки, транзакционная выдача лицензии, запрет самопроверки администратора, ограничения повторных попыток.

Лицензии — внутренние сертификаты FTCL, не документы UEFA или национальных федераций. Поставляемый контент — стартовая программа академии. Все уровни проверяют общие футбольные принципы; старшие уровни требуют более глубокого письменного разбора. Перед реальной аттестацией администратор должен утвердить программу, вопросы и рубрики.

## Быстрый локальный запуск

Нужен Node.js 22.12+ (проверено на 24.19).

```bash
cd /workspace/coach-with-me
npm ci
cp .env.example .env.local
# Заполните только URL и PUBLIC publishable/anon key Supabase.
npm run dev
```

Без `.env.local` доступны открытые учебные материалы, тренажёр, пробный тест и подготовленный наставник. Это открытый учебный режим: он не создаёт фиктивных аккаунтов, лицензий и сохранённого прогресса.

Для полноценных аккаунтов нужно применить обе SQL-миграции и развернуть две Edge Functions, как описано ниже. Одного URL и публичного ключа недостаточно.

## Бесплатные тарифы

Cloudflare Pages обслуживает статическую сборку, Supabase Free — Auth, БД и Edge Functions. Для этого проекта не нужны платный сервер, подписка на ИИ или Cloudflare Workers Paid. Доступность Free, квоты, число проектов, пауза при неактивности, ограничения email и условия провайдеров могут меняться: проверьте [Cloudflare Pages limits](https://developers.cloudflare.com/pages/platform/limits/) и [Supabase pricing](https://supabase.com/pricing) перед запуском.

ИИ по умолчанию выключен. Можно оставить так навсегда. Можно подключить провайдера с бесплатной квотой, установить `AI_PROVIDER` и серверный лимит. Это не создаёт бесплатный тариф у провайдера: не включайте платный автоперерасход, если расходы недопустимы. При исчерпании квоты/тайм-ауте интерфейс автоматически продолжает подготовленные занятия. Обычные уроки, практика и экзамены не вызывают ИИ.

Для публичной регистрации настройте SMTP (можно с бесплатным лимитом) и ограничения Auth: встроенный тестовый почтовый сервис Supabase имеет ограничения получателей/частоты. Без доставки писем не работают подтверждение email и восстановление пароля. Подробности — в инструкции Supabase.
